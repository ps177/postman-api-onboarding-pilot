# Collection exports (v2.1 JSON)

These are single-file Postman Collection v2.1 exports of the three
generated collections, for easy review and import.

The source of truth is `postman/collections/`, which is written by
postman-repo-sync-action in Postman's v3 YAML format (one file per
request). That folder is what the onboarding workflow keeps in sync.

These JSON files were exported manually from the Postman workspace
`[PAY] payment-refund-api` after onboarding run #2. They are a
point-in-time snapshot and are not updated by the workflow.
